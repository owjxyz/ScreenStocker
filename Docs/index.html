A BETTER IDLE SCREEN

볼 때는 선명하게.
쉴 때는 담백하게.

ScreenStocker는 선택한 한 종목의 현재가, 등락률, 차트와 업데이트 시각을 화면 전체에 펼칩니다. 복잡한 거래 화면을 열지 않아도 시장의 흐름을 가볍게 살펴볼 수 있습니다.

MADE FOR A GLANCE

필요한 것만, 원하는 모습으로.

관심 종목과 화면 표현은 함께 제공되는 관리 앱에서 설정합니다.

GET STARTED

설정은 앱에서.
표시는 화면 보호기에서.

처음 한 번 설정하면, 선택한 종목이 Mac의 화면 보호기에 나타납니다.

전체 설치 안내 보기 ↗
  1. 01

    API 자격 증명 저장

    관리 앱에 Toss Invest Open API 키를 입력합니다. 키는 macOS Keychain에 저장됩니다.

  2. 02

    관심 종목과 화면 설정

    관심 목록을 만들고, 표시할 종목·차트 스타일·화면 모드를 선택합니다.

  3. 03

    화면 보호기 적용

    관리 앱에서 화면 보호기를 설치한 뒤 macOS 시스템 설정에서 ScreenStocker를 선택합니다.

BEFORE YOU START

시작하기 전에

  • macOS 13 Ventura 이상
  • 인터넷 연결
  • Toss Invest Open API 자격 증명

현재 저장소의 설치 안내는 소스에서 직접 빌드하는 방법을 설명합니다. 빌드에는 XcodeGen이 필요합니다.
